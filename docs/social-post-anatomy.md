# PMP Social Posts — Current Anatomy (for review/optimization)

> Context: PreMarketPrice.com is a market-data + stock-analysis product.
> Core loop: abnormal move → why → fundamentals → historical context.
> Social posts exist to pull traders/investors from X / Bluesky / Threads
> back to the site. Goal of this doc: describe the current state precisely
> so another LLM can propose copy + visual improvements that raise CTR.

## 1. Trigger & cadence

- Cron `post-social`: every 30 min, Mon–Fri, 07:00–17:00 ET (13:00–22:59 Europe/Prague)
- **1 post per run**, hard cap **4 posts/day** (Redis quota), each symbol max 1×/day
- Eligibility (any of):
  - `|z-score| ≥ 4` AND `RVOL ≥ 2` (statistical outlier with volume confirmation)
  - `|day change| ≥ 5%` AND `RVOL ≥ 4` (volume-driven move)
- Plus: AI-generated `moversReason` + `socialCopy` must exist
- Ordering: highest z-score first; quantitative fallback copy if LLM unavailable

## 2. Post text (identical on X / Bluesky / Threads)

```
📉 $WDC -8.44% on Toshiba HDD capacity surge
Volume 4.1x, Z-score -2.96σ
#WDC #TechStocks

Full breakdown: https://premarketprice.com/analysis/WDC
```

- `socialCopy` is generated by an LLM (Gemini; quant fallback without key):
  line 1 = 📈/📉 + `$TICKER` cashtag + % move + short catalyst phrase;
  line 2 = key stat (RVOL x / Z-score σ); 🚨 only for |Z|≥4 or RVOL≥5;
  ends with `#TICKER` + 1 sector hashtag; no URLs, no targets, no advice
- At post time the % in text is **patched to the live value** so text and
  card never disagree
- Trailing "Full breakdown:" + analysis URL, per-channel UTM appended:
  `?utm_source={x|bluesky|threads}&utm_medium=social&utm_campaign=movers`
- Bluesky gets link facets (clickable $cashtag-less links + hashtags)

## 3. The card (1200×630 PNG, auto-generated per ticker)

Served at `/analysis/[ticker]/opengraph-image` — same card is used for
social posts **and every link share** (iMessage, Discord, LinkedIn…).

Layout (top→bottom, dark navy gradient #0f172a→#334155, 60px padding):

```
PreMarketPrice                                    (blue wordmark, 28px)

[logo]  TICKER          Sector                    (logo: 88px white
        Company name                              rounded badge;
                                                  ticker 72px bold;
                                                  name 32px gray)

$415.75   ▼ -10.12%              ▂▄▅▆▃▅▇▅▄▂      (price 48px + colored
                                                 change + 30-day
                                                 sparkline bars right)

[ PMP Health: 72/100 ]                            (green ≥70, amber ≥50,
                                                  red <50 rounded badge)

premarketprice.com/analysis/WDC   Live pre-market data & analysis
```

- Logo source: locally cached `public/logos/<sym>-64.webp` → PNG via sharp
  → data URI. Coverage ~2 560 tickers; .svg-only tickers (~77) fall back to
  no logo. No external fetch — zero cost per render.

## 4. Distribution mechanics

- **Buffer GraphQL API** (`createPost shareNow`) → `twitter` + `threads`
  channels, brand-scoped by channel name (`premarketprice`) — personal
  profiles connected to the same Buffer account are excluded
- **Bluesky** — direct AT Protocol: card uploaded as blob `thumb` on an
  `embed.external` (title+description+link card)
- **X via Buffer** — text + URL → platform unfurl renders the card.
  Direct X API fallback uploads the card as native media (v1.1
  uploadMedia is best-effort — free tier may 402 → unfurl still covers it)
- Buffer sends text-only → link preview card comes from OG tags

## 5. Known constraints / current weaknesses (candidate review points)

- Text is template-locked: emoji + % + catalyst + stats + hashtags —
  no hook, no question, no "why it matters", no comparative framing
  ("worst day since March", "biggest drop in sector today")
- Card shows price + % + health score + 30d sparkline, but **not the
  reason** — the "why" stays in text only
- No day-range/volume/z-score on the card; no PMP pillar scores
- Health badge label "PMP Health" may be opaque to non-users
- 4 posts/day, single-slot spacing via 30-min cron
- Free-plan Buffer: shareNow posts, 3-channel cap

## 6. What we want from the analysis

- Copy: higher-CTR text patterns for finance/movers audiences
  (hook-first? question? number-first? cashtag placement)
- Card: information hierarchy, what to add/remove/emphasize for
  clickability (e.g. bigger %?, reason on card?, sector context?,
  "vs 20-day average" framing?, day range bar?)
- Format leverage: Threads/X/Bluesky differences worth exploiting
- Any low-effort/high-impact additions (day high-low bar, market-cap
  chip, percentile badge "top 5% mover today", etc.)
