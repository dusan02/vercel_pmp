# PMP Social Posts — Current Anatomy (for review/optimization)

> Context: PreMarketPrice.com is a market-data + stock-analysis product.
> Core loop: abnormal move → why → fundamentals → historical context.
> Social posts exist to pull traders/investors from X / Bluesky / Threads
> back to the site. Goal of this doc: describe the current state precisely
> so another LLM can propose copy + visual improvements that raise CTR.

## 1. Trigger & cadence

- Cron `post-social`: every 30 min, Mon–Fri, 07:00–17:00 ET (13:00–22:59 Europe/Prague)
- **1 post per run**, hard cap **4 posts/day** (Redis quota), each symbol max 1×/day
- Eligibility (any of):
  - `|z-score| ≥ 4` AND `RVOL ≥ 2` (statistical outlier with volume confirmation)
  - `|day change| ≥ 5%` AND `RVOL ≥ 4` (volume-driven move)
- Plus: AI-generated `moversReason` + `socialCopy` must exist
- Ordering: highest z-score first; quantitative fallback copy if LLM unavailable

**Digest posts** (separate daily locks, outside the 4/day quota):
- `post-social-premarket` → "🔔 Before the open:" top movers preview, ~08:45 ET
- `post-social-recap` → "📊 Today's biggest movers:" close recap, ~16:05 ET
- 4 biggest movers by |day change| (3 gainers + 2 losers pool, $1+ price)
- **Posting-window guard** (`inPostingWindow`): posts only fire inside their
  ET window (premarket 07:00–09:45, recap 15:30–17:30, singles 06:30–17:30,
  weekdays) — `pm2 start --only` fires trigger scripts at registration, and
  an off-schedule run must not post a mislabeled digest mid-session and burn
  the daily lock. `?force=1` on the route bypasses for manual retries.

## 2. Post text (same template on X / Bluesky / Threads)

```
📉 $WDC -8.44% on Toshiba HDD capacity surge
Volume 4.1x, Z-score -2.96σ
#WDC #TechStocks

Full breakdown: https://premarketprice.com/analysis/WDC
```

- `socialCopy` is generated by an LLM (Gemini). The quantitative fallback
  uses the same skeleton (`📈 $SYM +N% — catalyst / RVOL | Z-score / #tags`)
  so fallback posts are visually indistinguishable.
  line 1 = 📈/📉 + `$TICKER` cashtag + % move + short catalyst phrase;
  line 2 = key stat (RVOL x / Z-score σ); 🚨 only for |Z|≥4 or RVOL≥5;
  ends with `#TICKER` + 1 sector hashtag; no URLs, no targets, no advice
- Digest catalysts go through `hasCatalystSubstance` — pure quant fragments
  ("0.1x relative volume", "statistical outlier", "surging on extreme
  volatility") are dropped; a line may show just `📈 $SYM +N%`. Falls back
  to "unusual volume" only when RVOL ≥ 2.
- At post time `patchSocialCopy` rewrites stored copy to live values:
  % patched to `lastChangePct`, 📈/📉 emoji swapped to the live sign,
  `RVOL N.Nx` and `Z-score N.NNσ` tokens refreshed (also normalizes
  casing variants Z-Score/Z-score:). The OG card and text can never
  disagree about direction or magnitude.
- Trailing "Full breakdown:" + analysis URL, per-channel UTM appended:
  `?utm_source={x|bluesky|threads}&utm_medium=social&utm_campaign=movers`
- Bluesky gets link facets (clickable $cashtag-less links + hashtags)
- **Bluesky 300-grapheme cap**: Bluesky counts full URL chars (no t.co
  shortening). If text exceeds 300, `bskyFitText` drops URL lines first
  (the `embed.external` card already carries the click target), then
  word-boundary truncates. Digest posts override the card to link the
  movers board instead of the top mover's analysis page.

## 3. The card (1200×630 PNG, auto-generated per ticker)

Served at `/analysis/[ticker]/opengraph-image` — same card is used for
social posts **and every link share** (iMessage, Discord, LinkedIn…).

Layout (top→bottom, dark navy gradient #0f172a→#334155, 60px padding):

```
PreMarketPrice                                    (blue wordmark, 28px)

[logo]  TICKER          Sector                    (logo: 88px white
        Company name                              rounded badge;
                                                  ticker 72px bold;
                                                  name 32px gray)

$415.75   ▼ -10.12%              ▂▄▅▆▃▅▇▅▄▂      (price 48px + colored
                                                 change + 30-day
                                                 sparkline bars right)

[ PMP Health: 72/100 ]                            (green ≥70, amber ≥50,
                                                  red <50 rounded badge)

premarketprice.com/analysis/WDC   Live pre-market data & analysis
```

- Logo source: locally cached `public/logos/<sym>-64.webp` → PNG via sharp
  → data URI. Coverage ~2 560 tickers; .svg-only tickers (~77) fall back to
  no logo. No external fetch — zero cost per render.

## 4. Distribution mechanics

- **Buffer GraphQL API** (`createPost shareNow`) → `twitter` + `threads`
  channels, brand-scoped by channel name (`premarketprice`) — personal
  profiles connected to the same Buffer account are excluded
- **Bluesky** — direct AT Protocol: card uploaded as blob `thumb` on an
  `embed.external` (title+description+link card)
- **X via Buffer** — text + URL → platform unfurl renders the card.
  Direct X API fallback uploads the card as native media (v1.1
  uploadMedia is best-effort — free tier may 402 → unfurl still covers it)
- Buffer sends text-only → link preview card comes from OG tags

## 5. Known constraints / current weaknesses (candidate review points)

- Text is template-locked: emoji + % + catalyst + stats + hashtags —
  no hook, no question, no "why it matters", no comparative framing
  ("worst day since March", "biggest drop in sector today")
- Card shows price + % + health score + 30d sparkline, but **not the
  reason** — the "why" stays in text only
- No day-range/volume/z-score on the card; no PMP pillar scores
- Health badge label "PMP Health" may be opaque to non-users
- 4 posts/day, single-slot spacing via 30-min cron
- Free-plan Buffer: shareNow posts, 3-channel cap

## 6. What we want from the analysis

- Copy: higher-CTR text patterns for finance/movers audiences
  (hook-first? question? number-first? cashtag placement)
- Card: information hierarchy, what to add/remove/emphasize for
  clickability (e.g. bigger %?, reason on card?, sector context?,
  "vs 20-day average" framing?, day range bar?)
- Format leverage: Threads/X/Bluesky differences worth exploiting
- Any low-effort/high-impact additions (day high-low bar, market-cap
  chip, percentile badge "top 5% mover today", etc.)

## 7. Instructions for the analyzing LLM

**Output discipline — for every proposed improvement:**

- Classify as: `High impact / low effort` · `High impact / medium
  effort` · `Low impact / low effort` · `Not worth implementing`
- Provide: current behavior → proposed behavior → example of the
  resulting post → why it should work → implementation complexity →
  potential downside
- Do not recommend changes merely because they are possible; prioritize
  changes that can realistically improve CTR, engagement, ticker
  recognition, or conversion to PMP visits while preserving the fully
  automated nature of the system
- Do not redesign the whole system unless there is a clear measurable
  benefit
- Concrete deliverable style: "Change X now → reason → new template →
  rendered example" — not "consider making it more engaging"

**Strategic question to answer first:**

Analyze whether PMP should optimize social posts primarily for
information density, curiosity/hook, credibility, or click-through rate.
Explain the trade-offs and propose the optimal balance for an
*automated* financial-market account (PMP differs from a classic
finance X account: every post is generated, there is no human persona,
and the destination — not the post — carries the full analysis).

**Evaluate these areas explicitly:**

| Area | Question |
|---|---|
| Hook | Are the first 5–10 words compelling enough? |
| Why | Is it instantly clear *why* the stock moved? |
| Numbers | Right amount of numbers — or too many? |
| Ticker | Is the ticker immediately visible? |
| CTA | Does the post give a natural reason to click through to PMP? |
| Card | What does a person see in the first 1 second? |
| Health | Is "PMP Health" understandable without knowing PMP? |
| Platform | Should X/Threads/Bluesky text be identical? |
| Automation | What can be personalized without materially raising complexity? |
| CTR | Which changes most plausibly raise clicks? |
| Brand | What strengthens PMP as a product vs. a generic stock-tweet bot? |
